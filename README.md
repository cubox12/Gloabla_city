# GLOBAL CITY 0.3

Prototipo 3D para Godot 4.x, base Android con renderer Compatibility.

Estado: plataforma 140x140, calles en cuadrícula, aceras, personaje low-poly inmóvil, cámara fija y entorno procedural. El proyecto prioriza una escena ligera para móviles.

## Proyecto fuente
El paquete fuente completo `GLOBAL_CITY_0.3_source.zip` fue proporcionado en esta conversación. La importación del contenido al repositorio se está realizando por etapas; no se considera completada hasta verificar todos los archivos.

## Abrir
Abre `project.godot` en Godot 4.x. Para regenerar texturas y validar: `python3 tools/generate_textures.py` y `python3 tools/validate_project.py`.

No se incluye APK. La exportación Android requiere Godot Export Templates, Android SDK y JDK. No se han medido FPS en dispositivo real.
